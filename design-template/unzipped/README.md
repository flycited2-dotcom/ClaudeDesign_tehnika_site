# БытТехОпт — прототип интернет-магазина бытовой техники

Хай-фай прототип магазина с тремя режимами (Розница / Опт / Госзакупки) и Telegram-агентом продаж.

## Запуск

Откройте `Магазин.html` в браузере. Никакой сборки не требуется — Babel компилирует JSX на лету.

## Экраны

- **Главная** — `screen-home.jsx`
- **Каталог** — `screen-catalog.jsx`
- **Карточка товара** — `screen-product.jsx`
- **Корзина** — `screen-cart.jsx`
- **Оформление заказа** — `screen-checkout.jsx`
- **Личный кабинет** — `screen-account.jsx`
- **B2B-портал** — `screen-b2b.jsx`
- **Госзакупки** — `screen-gov.jsx`
- **Telegram-агент** — `screen-bot.jsx` (5 сценариев диалога)

## Структура

- `Магазин.html` — точка входа, подключает все скрипты
- `app.jsx` — корневой компонент, роутинг между экранами, стейт корзины и роли
- `chrome.jsx` — шапка, футер, нижняя панель навигации
- `styles.css` — все стили
- `data.jsx` — каталог товаров, категории
- `icons.jsx` + `icon-shim.jsx` — SVG-иконки
- `assets/` — логотип и ассеты бренда
