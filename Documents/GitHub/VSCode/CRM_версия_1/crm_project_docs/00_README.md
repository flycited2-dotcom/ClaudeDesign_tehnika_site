# Проект CRM-системы для торговой компании

Пакет документации подготовлен как основа для проектирования, разработки, проверки и приемки собственной CRM-системы компании.

## Состав архива

1. `01_TZ_CRM.md` — основное техническое задание.
2. `02_ARCHITECTURE.md` — техническая архитектура системы.
3. `03_ROLES_ACCESS.md` — роли, права и матрица доступов.
4. `04_BUSINESS_PROCESSES.md` — бизнес-процессы CRM.
5. `05_DATABASE_SCHEMA.md` — структура базы данных.
6. `06_API_SPEC.md` — проект API.
7. `07_UI_UX_SPEC.md` — структура интерфейсов и экранов.
8. `08_DEVELOPMENT_ROADMAP.md` — этапы разработки.
9. `09_ACCEPTANCE_CHECKLIST.md` — контрольные точки и чек-лист приемки.
10. `10_DEVELOPER_INSTRUCTIONS.md` — инструкции разработчикам.

## Главный принцип проекта

CRM не заменяет 1С. 1С остается учетной системой для товаров, складов, резервов, счетов, реализаций и бухгалтерии. CRM является управленческим контуром: заявки, клиенты, сделки, задачи, КП, коммуникации, контроль сотрудников, интеграции с сайтами и аналитика собственника.

## Приоритет первой версии

MVP должен решить главную управленческую задачу: ни одна заявка, задача, сделка, КП или тендерный срок не должны теряться.
