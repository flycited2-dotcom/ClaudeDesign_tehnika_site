# План разработки CRM

## 1. Общий подход

Разработка должна идти по этапам. Нельзя начинать с интеграций и второстепенных функций. Сначала делается ядро CRM, затем подключения и автоматизация.

## 2. Этап 0. Подготовка проекта

Задачи:

- создать репозиторий;
- настроить backend;
- настроить frontend;
- подключить PostgreSQL;
- подключить Redis;
- настроить env;
- настроить миграции;
- настроить Swagger;
- настроить базовый CI/CD;
- подготовить Docker Compose для локальной разработки.

Результат:

- проект запускается локально;
- backend отвечает;
- frontend открывается;
- база подключена;
- миграции работают.

## 3. Этап 1. Авторизация и роли

Задачи:

- users;
- roles;
- permissions;
- login;
- logout;
- refresh token;
- RBAC guard;
- фиксация входа/выхода;
- базовая админка пользователей.

Контрольная точка:

- можно создать пользователя;
- можно войти;
- права ограничивают разделы;
- вход фиксируется в work_sessions.

## 4. Этап 2. Клиенты

Задачи:

- CRUD клиентов;
- контакты клиентов;
- поиск;
- фильтры;
- карточка клиента;
- комментарии;
- файлы;
- история действий.

Контрольная точка:

- менеджер создает клиента;
- собственник видит всех клиентов;
- менеджер видит своих клиентов;
- история действий сохраняется.

## 5. Этап 3. Лиды

Задачи:

- CRUD лидов;
- статусы;
- назначение ответственного;
- конвертация в клиента/сделку;
- правило 15 минут;
- уведомления.

Контрольная точка:

- новый лид создается;
- лид назначается менеджеру;
- при задержке обработки отправляется уведомление.

## 6. Этап 4. Сделки и воронки

Задачи:

- CRUD сделок;
- направления;
- этапы;
- канбан;
- связь с клиентом;
- товары сделки;
- смена статусов;
- сделки без движения.

Контрольная точка:

- сделка создается из лида;
- сделка двигается по воронке;
- собственник видит проблемные сделки.

## 7. Этап 5. Задачи

Задачи:

- CRUD задач;
- дедлайны;
- приоритеты;
- статусы;
- комментарии;
- уведомления;
- просрочки;
- автоматические задачи.

Контрольная точка:

- задача назначается сотруднику;
- исполнитель получает уведомление;
- просрочка видна собственнику.

## 8. Этап 6. КП

Задачи:

- шаблоны КП;
- компании-отправители;
- товары КП;
- расчет сумм;
- НДС/без НДС;
- генерация PDF;
- отправка email;
- сохранение в сделке.

Контрольная точка:

- менеджер создает КП;
- PDF генерируется;
- КП можно отправить email;
- КП хранится в сделке.

## 9. Этап 7. Telegram-уведомления

Задачи:

- Telegram Bot;
- привязка сотрудников;
- уведомления о лидах;
- уведомления о задачах;
- уведомления о просрочках;
- уведомления собственнику.

Контрольная точка:

- новый лид приходит в Telegram;
- задача приходит исполнителю;
- просрочка приходит руководителю и собственнику.

## 10. Этап 8. Дашборды и отчеты

Задачи:

- рабочий стол собственника;
- рабочий стол менеджера;
- отчеты по задачам;
- отчеты по лидам;
- отчеты по КП;
- отчеты по рабочему времени.

Контрольная точка:

- собственник видит управленческую картину;
- менеджер видит свои рабочие задачи.

## 11. Этап 9. Интеграция сайтов

Задачи:

- webhook API;
- токены сайтов;
- прием заявок;
- UTM;
- создание лидов;
- распределение заявок.

Контрольная точка:

- заявка с сайта создает лид в CRM.

## 12. Этап 10. Тендерный модуль

Задачи:

- карточка тендера;
- документы;
- статусы;
- дедлайны;
- задачи;
- уведомления;
- результат.

Контрольная точка:

- можно вести тендер от найденного до результата.

## 13. Этап 11. Интеграция с 1С

Задачи:

- согласовать протокол обмена;
- клиенты;
- заказы;
- резервы;
- счета;
- оплаты;
- остатки;
- статусы.

Контрольная точка:

- CRM отправляет запрос в 1С;
- 1С возвращает статус;
- ошибка синхронизации фиксируется.
