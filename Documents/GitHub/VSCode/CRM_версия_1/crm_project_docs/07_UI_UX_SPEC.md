# UI/UX спецификация CRM

## 1. Общие требования к интерфейсу

Интерфейс должен быть быстрым, чистым, без перегруза. Система создается для ежедневной работы сотрудников, поэтому важны скорость, простота и контроль.

Основная структура:

- левое меню;
- верхняя панель;
- рабочая область;
- уведомления;
- быстрые действия;
- карточки сущностей.

## 2. Главное меню

Пункты:

1. Рабочий стол
2. Клиенты
3. Лиды
4. Сделки
5. Задачи
6. КП
7. Тендеры
8. Коммуникации
9. Сотрудники
10. Отчеты
11. Настройки

Пункты меню скрываются/показываются по правам доступа.

## 3. Верхняя панель

Элементы:

- поиск;
- кнопка “Создать”;
- уведомления;
- профиль пользователя;
- статус рабочего дня;
- быстрый переход к задачам.

## 4. Рабочий стол собственника

Блоки:

### KPI-карточки

- новые заявки сегодня;
- необработанные заявки;
- активные сделки;
- просроченные задачи;
- отправленные КП;
- сотрудники онлайн;
- тендерные дедлайны.

### Таблица сотрудников

Колонки:

- сотрудник;
- роль;
- время входа;
- время выхода;
- отработано часов;
- задач выполнено;
- задач просрочено;
- КП отправлено;
- активные сделки.

### Проблемные зоны

- лиды без ответственного;
- лиды без обработки более 15 минут;
- сделки без движения более 3 дней;
- просроченные задачи;
- КП без ответа более 24 часов;
- тендеры со сроком менее 48 часов.

## 5. Рабочий стол менеджера

Блоки:

- мои задачи на сегодня;
- просроченные задачи;
- новые лиды;
- активные сделки;
- КП на контроле;
- последние сообщения;
- быстрые действия.

Быстрые действия:

- создать клиента;
- создать сделку;
- создать задачу;
- создать КП;
- добавить комментарий.

## 6. Экран клиентов

Функции:

- таблица клиентов;
- поиск;
- фильтр по типу;
- фильтр по статусу;
- фильтр по ответственному;
- фильтр по источнику;
- кнопка создания клиента;
- импорт из Excel.

Колонки:

- название / ФИО;
- тип;
- телефон;
- email;
- ответственный;
- статус;
- последняя активность;
- сумма сделок.

## 7. Карточка клиента

Вкладки:

1. Общее
2. Контакты
3. Сделки
4. КП
5. Задачи
6. Сообщения
7. Файлы
8. История

В правой части карточки — быстрые действия:

- создать сделку;
- создать задачу;
- создать КП;
- отправить сообщение;
- загрузить файл.

## 8. Экран лидов

Представления:

- список;
- канбан по статусам.

Фильтры:

- источник;
- сайт;
- ответственный;
- статус;
- дата поступления;
- необработанные.

Цветовые маркеры:

- новый лид — синий;
- без обработки более 15 минут — красный;
- в работе — желтый;
- квалифицирован — зеленый;
- отказ — серый.

## 9. Экран сделок

Представления:

- канбан;
- таблица;
- список по клиентам.

Фильтры:

- направление;
- воронка;
- этап;
- ответственный;
- сумма;
- дата создания;
- сделки без движения.

Карточка сделки в канбане показывает:

- номер;
- клиента;
- сумму;
- ответственного;
- дату последнего действия;
- наличие просроченных задач;
- количество КП.

## 10. Карточка сделки

Вкладки:

1. Обзор
2. Товары
3. КП
4. Задачи
5. Коммуникации
6. Файлы
7. История

Кнопки:

- создать КП;
- поставить задачу;
- добавить товар;
- добавить комментарий;
- отправить сообщение;
- запросить резерв в 1С — этап 2;
- выставить счет — этап 2;
- закрыть сделку.

## 11. Экран задач

Представления:

- мои задачи;
- задачи отдела;
- все задачи;
- канбан;
- календарь.

Фильтры:

- исполнитель;
- постановщик;
- статус;
- приоритет;
- дедлайн;
- просроченные;
- связанные с клиентом/сделкой/тендером.

## 12. Экран КП

Функции:

- список КП;
- фильтр по статусу;
- фильтр по клиенту;
- фильтр по менеджеру;
- создание КП;
- просмотр PDF;
- отправка email;
- отправка Telegram;
- история версий.

## 13. Экран тендеров

Функции:

- список тендеров;
- календарь дедлайнов;
- статусы;
- документы;
- задачи;
- расчет цены;
- итоговый результат.

## 14. Экран отчетов

Для собственника:

- общая панель;
- отчет по задачам;
- отчет по менеджерам;
- отчет по КП;
- отчет по лидам;
- отчет по сделкам;
- отчет по рабочему времени;
- отчет по тендерам.
