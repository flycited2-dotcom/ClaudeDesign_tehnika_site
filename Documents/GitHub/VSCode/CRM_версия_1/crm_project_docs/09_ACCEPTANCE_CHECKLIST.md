# Контрольные точки и чек-лист приемки CRM

## 1. Общие правила приемки

Каждый модуль считается готовым только если:

- функция работает в интерфейсе;
- API работает;
- права доступа соблюдаются;
- ошибки обрабатываются;
- действия пишутся в журнал;
- данные сохраняются в базе;
- нет критичных багов;
- сценарий проверен на роли собственника, менеджера и администратора.

## 2. Авторизация

Проверить:

- пользователь может войти;
- неверный пароль не пускает;
- выход фиксируется;
- время входа сохраняется;
- время выхода сохраняется;
- заблокированный пользователь не может войти;
- разные роли видят разные разделы.

Критерий приемки: авторизация безопасна, роли работают, рабочее время фиксируется.

## 3. Клиенты

Проверить:

- создание клиента;
- редактирование клиента;
- добавление телефона;
- добавление email;
- добавление Telegram;
- фильтры;
- поиск;
- карточка клиента;
- сделки клиента;
- задачи клиента;
- КП клиента;
- история действий.

Критерий приемки: клиентская база работает как единый справочник.

## 4. Лиды

Проверить:

- ручное создание лида;
- создание лида через webhook;
- назначение ответственного;
- смена статуса;
- конвертация в сделку;
- закрытие как дубль;
- уведомление при новом лиде;
- уведомление при необработке 15 минут.

Критерий приемки: входящие заявки не теряются.

## 5. Сделки

Проверить:

- создание сделки;
- связь с клиентом;
- добавление товаров;
- смена этапа;
- канбан;
- фильтры;
- комментарии;
- файлы;
- закрытие успешно;
- закрытие отказом;
- фиксация причины отказа.

Критерий приемки: сделка проходит весь путь от создания до закрытия.

## 6. Задачи

Проверить:

- создание задачи;
- назначение исполнителя;
- дедлайн;
- приоритет;
- уведомление исполнителя;
- смена статуса;
- выполнение;
- просрочка;
- уведомление руководителя и собственника;
- связь с клиентом/сделкой/тендером.

Критерий приемки: задачи контролируются, просрочки видны.

## 7. КП

Проверить:

- создание КП из сделки;
- выбор клиента;
- выбор шаблона;
- добавление товаров;
- расчет суммы;
- НДС;
- без НДС;
- генерация PDF;
- сохранение PDF;
- отправка email;
- запись события в историю сделки.

Критерий приемки: менеджер может создать и отправить КП без ручной сборки документа.

## 8. Telegram

Проверить:

- привязка Telegram сотрудника;
- уведомление о новом лиде;
- уведомление о задаче;
- уведомление о просрочке;
- уведомление собственнику;
- обработка ошибки отправки.

Критерий приемки: ключевые события доходят в Telegram.

## 9. Рабочее время

Проверить:

- вход фиксируется;
- выход фиксируется;
- отчет по дню строится;
- собственник видит сотрудников;
- отображаются часы;
- IP и устройство сохраняются.

Критерий приемки: собственник видит базовую дисциплину присутствия.

## 10. Отчеты

Проверить:

- отчет по лидам;
- отчет по сделкам;
- отчет по задачам;
- отчет по КП;
- отчет по рабочему времени;
- отчет по менеджерам.

Критерий приемки: собственник получает управленческую картину.

## 11. Сайты

Проверить:

- webhook принимает заявку;
- неверный токен отклоняется;
- создается лид;
- сохраняется сайт и URL;
- сохраняются UTM;
- назначается ответственный;
- отправляется уведомление.

Критерий приемки: сайт подключен к CRM.

## 12. Тендеры

Проверить:

- создание тендера;
- добавление сроков;
- добавление документов;
- создание задач;
- уведомление о дедлайне;
- смена статуса;
- фиксация результата.

Критерий приемки: тендер можно контролировать внутри CRM.

## 13. Интеграция 1С

Проверить на втором этапе:

- CRM отправляет клиента в 1С;
- CRM отправляет заказ/резерв;
- 1С возвращает статус;
- ошибка пишется в integration_logs;
- повторная отправка работает;
- пользователь видит статус синхронизации.

Критерий приемки: CRM и 1С обмениваются данными без ручного дублирования.

## 14. Финальная приемка MVP

MVP принят, если:

- собственник может контролировать сотрудников;
- менеджеры ведут клиентов, лиды, сделки и задачи;
- КП создаются и отправляются;
- Telegram-уведомления работают;
- рабочее время фиксируется;
- базовые отчеты работают;
- система не теряет заявки;
- права доступа корректны;
- журнал действий ведется;
- критичных багов нет.
