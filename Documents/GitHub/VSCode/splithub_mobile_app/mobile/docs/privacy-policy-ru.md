# Политика конфиденциальности SplitHub

Статус: черновик для юридической проверки перед публикацией.

## Оператор

Перед публикацией укажите юридическое наименование оператора SplitHub,
реквизиты и контакт для запросов субъектов персональных данных.

## Какие данные обрабатываются

- имя и номер телефона;
- необязательный Telegram-аккаунт;
- история заказов и их статусы;
- Expo push-токен устройства;
- настройки получения уведомлений.

## Для чего используются данные

Данные используются для входа в аккаунт, оформления и сопровождения заказов,
связи с клиентом и отправки выбранных клиентом уведомлений.

## Хранение и удаление

Данные хранятся в течение срока, необходимого для обслуживания аккаунта,
исполнения заказов и выполнения требований законодательства. Запрос на
уточнение или удаление данных можно направить на info@splithub.ru.

## Публикация

После юридической проверки разместите финальную версию политики на публичном
HTTPS-адресе в домене splithub.ru и укажите этот адрес во всех магазинах.
