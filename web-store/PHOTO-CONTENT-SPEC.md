## 0. Главный принцип стиля (соблюдать во ВСЕХ изображениях)

Сайт сделан в стиле **glassmorphism**: светлый, воздушный, премиальный, «технологичный».
Любое генерируемое фото должно «лечь» в этот стиль, а не выбиваться.

**Палитра (токены `:root`, `src/styles/glass-template.css`):**
- Акценты: синий `--accent #4f7dff`, насыщенный синий `--accent-2 #2457e8`, фиолетовый `--violet #8068ff`.
- Тёплый декор: персик `--peach #ffd5c2`.
- Фон-база: `--bg-base #eef4ff` (холодный голубой), плюс тёплые блики персика.
- Фон заглушек (из `api/product-images/[id]/route.ts`): мягкий градиент `#f4f4f5 → #e7f5f1 → #fff7ed`.
- Текст: `--text #10204a`, приглушённый `--text-mute #5c6a8c`.

**Общие правила рендера:**
- Фон — светлый, мягкий градиент (голубой→белый→тёплый персик), БЕЗ тёмных/контрастных сцен.
- Освещение — рассеянное, дневное, мягкие тени, лёгкое отражение под объектом.
- Формы — скруглённые, чистые; никакого визуального шума, мусора, лишнего реквизита.
- Настроение — премиум, спокойствие, доверие; «техника, которая вдохновляет» (слоган hero).
- Запрещено: тёмные фоны, агрессивные тени, кислотные цвета, водяные знаки, текст на самом фото
  (текст накладывает сайт), логотипы чужих брендов, низкое разрешение, артефакты.
- Формат выдачи: **PNG** (для товаров и заглушек — с прозрачным ИЛИ светлым фоном, объект по центру),
  **JPG/WebP** допустим для фоновых баннеров/hero. Цветовое пространство sRGB.

## 2. Товарные фото (per-SKU) — отдельный масштабный пайплайн · **P0 по объёму**

- **Архитектура:** ВСЕ товарные слоты (карточка `glass-product-card.tsx:86`, галерея `product-gallery.tsx`,
  миниатюры, поиск `header-search-control.tsx:162`, сравнение `compare-table.tsx:166`) берут изображение из
  ОДНОГО источника: `productImageSrc()` (`src/lib/product-images.ts:13`) → `/api/product-images/[id]`.
  **Достаточно наполнить фото в БД/синке — весь UI подхватит автоматически.**
- **Объём:** **144 486 из 360 762** товаров без фото (~40%); поле `hasImage` врёт у ~3% (нужен `onError`-fallback).
- **Канонический формат:** **800×800 (1:1)**, объект по центру, светлый/прозрачный фон, object-fit contain.
  Детальная галерея использует кроп **4:3** из того же исходника.
- **Это не ручной дизайн, а конвейер:** генерация/подбор по названию+бренду+категории SKU. Вне объёма
  «дизайнерских» 6–8 фото выше; планировать отдельно (источник у поставщика ИТП + генерация для остатка).
