- [x] ✅ **9. Аудит админки** 🟡 (Iter 75, 2026-07-01) — code-review без живого логина (владелец предпочёл не выдавать креды на данном этапе). Прочитаны все разделы (обзор/товары/категории/заказы/лиды/заявки на роли/синхронизация/настройки/логи) и все server actions. Найден и пофикшен реальный баг: кнопки синка в `/admin/sync` не имели защиты от повторного запуска — `syncItpProducts`/`syncItpImages` идут построчным upsert без батчинга по всему каталогу (часы), дольше `proxy_read_timeout`; повторный клик после видимого таймаута запускал второй параллельный синк по тем же строкам.
